03 — CURRENT RESEARCH

🔬 Semantic Chunking × RAG

Can better chunk boundaries improve retrieval quality?

</div>

I'm experimenting with semantic chunking and comparing different threshold strategies to understand how the information passed to an LLM changes.

<div align="center">

Stage

Experiment

01

Document → Sentences

02

Sentences → Embeddings

03

Embeddings → Similarity

04

Similarity → Threshold

05

Threshold → Chunk Boundaries

06

Chunks → Retrieval

07

Retrieval → RAG Quality

<br/>

Absolute threshold   •   Relative threshold   •   Percentile threshold

</div>

What I'm measuring

Semantic coherence

Chunk size distribution

Context preservation

Boundary behaviour

Retrieval quality

The goal isn't just to make chunks. The goal is to understand why one strategy works better than another.
